1. TARGET PLATFORM SETTINGS (read back from ProjectSettings/ProjectSettings.asset)
----------------------------------------------------------------------------
Build target            : Android
Bundle identifier       : com.defaultcompany.dama
Minimum API level       : Android 8.0 (API 26)
Target API level        : Automatic - highest installed
CPU architecture        : ARM64 only
Scripting backend       : IL2CPP  (ProjectSettings.asset line 648-649: scriptingBackend / Android: 1)
Internet permission     : NOT requested (ForceInternetPermission: 0)

Why these values were chosen for this game:
  - API 26 is the floor that current Unity 6 Android builds support, so no
    device that can install the game is excluded by a needless restriction.
  - ARM64 only, because 32-bit ARM is no longer accepted by Google Play for
    new submissions; shipping one architecture keeps the download small.
  - IL2CPP, because it produces a native build that is harder to decompile
    than the Mono scripting backend. That backs up the same point as the
    signed profile: the delivered game resists casual editing.
  - No internet permission, because Dama is an offline two-player board game
    and the profile is local. The app declares only what it actually uses.

----------------------------------------------------------------------------
2. HOW THESE SETTINGS WERE APPLIED
----------------------------------------------------------------------------
They were not clicked together by hand. They are applied by a script:

  Assets/Scripts/Editor/AndroidBuildSetup.cs

  Unity menu:  Tools > Android > Apply Mobile Build Settings

The script sets the target architecture, the scripting backend, the minimum
API level and puts the game scene first in the build list. Running it again is
idempotent - it re-applies the same values. This means the settings can be
reproduced from the repository instead of being a screenshot of a window.
