The states were produced through the game's own entry points (StartGame, ShowHowTo, CloseHowTo,
ShowCredits, CloseCredits, PauseGame, ReturnToMenu, CheckForWin). Only the board seeding is done
by reflection, the same way the Week 13-16 harnesses seed a position.

Seeding the grid by reflection changes what the game believes is on the board, not what is
drawn on it, so the harness rebuilds the visible pieces from the grid before each in-match
capture and refreshes the HUD. The "Rebuilt N visible piece(s)" lines above are that step, and
they are what makes the counts in the pictures checkable against the transcript.

The first run of this harness wrote six names over four pictures: the editor window was not the
foreground application, so the Game view stopped drawing after E3 and E4, E5 and E6 came back byte for
byte identical to it. The run now asks for a repaint (RepaintAllViews + QueuePlayerLoopUpdate) on every
tick while a shot is pending, hashes each landed PNG, and reports a collision instead of a success. The
"All 6 images are byte-distinct" line above is that check passing, not a claim.
