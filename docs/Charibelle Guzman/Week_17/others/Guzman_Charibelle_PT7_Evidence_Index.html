1. How to read this index

Every claim in the Week 17 package is listed once, with the file that proves it and - where a harness produced it - the case id inside that file. A claim with no row here does not belong in the documents, and a row whose evidence file is missing means the claim has to be withdrawn, not softened.

Two rules were applied while building the table:

  • A pass is a measurement, not an opinion. "The caption is correct" is only a claim because TC-REL-01 compared the on-screen string to Application.version; the comparison is in the log.
  • Something that could not be measured is listed as not measured. The rows in section 5 are in this index precisely so that a reader can see the holes without hunting for them.
