The profile images are taken against a scratch data directory, because the demonstration has
to show a record and then erase it, and the record on this machine belongs to whoever played.
PlayerProfile.SetDataDirectory points the store at a temporary folder, three matches are banked
there, and the real directory is pointed back at its own folder only after D9 - because the last
match ends through the game's own win check, and that check banks the match. The "Real profile
directory" and "Profile directory restored" lines above are that round trip; the match
images therefore bank into the temporary folder, not into the player's own record.

Every other state is produced through the game's own entry points (ShowHowTo, ShowCredits,
ShowProfile, ResetPressed, StartGame, RestartGame, PauseGame, ResumeGame, ReturnToMenu,
CheckForWin). Only the board seeding is done by reflection, and the visible pieces are then
rebuilt from the grid so the picture matches the state the transcript describes.
