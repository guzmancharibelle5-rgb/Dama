## How to read this file

Every field below is blank because the defense has not taken place. This file is the *form* the viva fills in,
not a record of one that happened. A blank field means **not run**, and must never be read as a pass, as a
satisfactory answer, or as a question that was not asked.

Filling any part of this in before the session — with an expected outcome, a rehearsal score, or a prediction —
would turn evidence into fabrication. The submission's rule is the same one `final_pre_submission_checklist.md`
uses for the installable build: unproven stays unproven.

`defense_prep.md` is the companion file: it holds the questions and where the true answers live in the repository,
and **no answers**.
