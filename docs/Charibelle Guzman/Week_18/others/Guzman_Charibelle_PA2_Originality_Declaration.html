1. Declaration

I declare that this project is my own work, produced for MOBILE DEV 002 Module 5, and that:

  1. The game design, the rule implementation, the interface, the player-data design, the tests and the documents in this submission were produced by me for this course, with the AI assistance disclosed in §6 and nowhere beyond it.
  2. The source code is my own except where a file states otherwise. No code was copied from another student's submission, from a tutorial repository, or from an asset store package.
  3. The game art is generated in code at runtime — squares, men and Dama are drawn from sprites the project builds itself — so no third-party art asset is redistributed in this submission.
  4. The audio feedback clips are generated by the project's own toolchain, not sampled from a commercial recording.
  5. Every measured value in the documents traces to a harness log or a command output produced on this machine, and every gap is labelled BLOCKED, NOT MEASURABLE or NOT RUN rather than filled in.
  6. No part of this submission was submitted for credit in another course.

4. Sources consulted

The rules were implemented from the game as it is played, with the shell of the implementation checked against public descriptions of draughts families. The engineering method — profile first, then change one thing at a time, then re-measure — follows the Unity guidance listed in the module's resource list (the mobile-performance guide and the Profiler documentation), and the accessibility thresholds follow WCAG 2.2 (SC 1.4.4 for text size and SC 1.4.11 for non-text contrast). No code was lifted from those sources; they informed the thresholds and the order of work.
