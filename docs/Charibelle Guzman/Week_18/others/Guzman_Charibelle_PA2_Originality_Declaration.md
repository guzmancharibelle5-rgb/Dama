## 4. Sources consulted

The rules were implemented from the game as it is played, with the shell of the implementation checked
against public descriptions of draughts families. The engineering method — profile first, then change
one thing at a time, then re-measure — follows the Unity guidance listed in the module's resource list
(the mobile-performance guide and the Profiler documentation), and the accessibility thresholds follow
WCAG 2.2 (SC 1.4.4 for text size and SC 1.4.11 for non-text contrast). No code was lifted from those
sources; they informed the thresholds and the order of work.
